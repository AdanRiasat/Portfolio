# Portfolio

Portfolio site of yours truly.

## 🌐 Live Website

Hosted on Vercel

Link: https://riasat.me

## Tech stack

HTML,
CSS,
JS,
GitHub API,
Vercel.

## Features

### List of Projects

Holds the list of all my personal projects with different filters and categories.

### GitHub API for README

Each project has a button to display its README from GitHub in a modal.

### SVG images and animations

An animation of my signature plays when the page refreshes.

Other images are used on the hero section as well as for the project images.

### Many JS and CSS animations

Various animations on the page, done with JS and CSS.
